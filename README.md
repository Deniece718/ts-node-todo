# file-service

## About this Project

File Service is a lightweight web app for uploading, validating, and managing files through an S3-compatible storage workflow. It provides a small, practical codebase that combines:

- A modern TypeScript + Vite frontend UI for file selection, upload progress, and list management
- A backend upload API with s3 upload helpers and metadata handling
- Expandable storage abstraction for local/dev or S3-compatible providers

### Deploy

- **Clone and Install Dependencies**

```bash
git https://github.com/Deniece718/file-service.git
cd file-service
npm install
```

- **Build and Run**

```bash
npm run build && npm run start
```
